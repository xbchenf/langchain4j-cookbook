全栈开发工程师（SaaS 分析平台，欧盟远程）
------------------------------------------------
我们正在寻找一位**全栈开发工程师**加入我们的 SaaS 分析平台团队。这个角色需要同时处理后端和前端工作，专注于在数据密集型产品中提供高质量的用户体验。
**职责：**
*   使用 **Java** 或 **Node.js** 开发和维护后端服务，数据存储在 **PostgreSQL** 和 **Redis** 中。
*   使用 **React** 构建和增强仪表板和管理工具。
*   与产品经理和设计师合作，端到端地发布功能。
*   为扩展异步作业系统以进行数据处理做出贡献。
**要求：**
*   具有后端开发（Java 或 Node.js）的扎实经验。
*   具有现代 JavaScript 框架的实践经验，最好是 React。
*   对数据库和缓存解决方案有深入理解。
*   能够在远程团队中独立工作，并将功能从概念推进到生产环境。
*   有交付 SaaS 产品经验者优先。
*   要求流利的英语。
