后端工程师（金融科技，北京）
-----------------------------------
我们正在寻找一位**后端工程师**来帮助我们构建和发展支付和对账服务。你将主要使用 **Java（Spring Boot）**，并与产品和运营团队紧密合作，确保可靠、可扩展的金融交易。
**职责：**
*   设计、实现和维护处理大规模支付和对账的后端服务。
*   在云原生环境中使用 **PostgreSQL**、**Kafka**、**Docker** 和 **Kubernetes**。
*   专注于构建具有强大可观测性的可靠且幂等的系统。
*   支持将传统服务迁移到现代 REST API。
**要求：**
*   具有 Java 和 Spring Boot 后端开发的专业经验。
*   对关系型数据库和事件驱动架构有深入理解。
*   熟悉容器化和部署流水线。
*   有金融或定价系统经验者优先。
*   要求流利的英语；会中文者优先。
