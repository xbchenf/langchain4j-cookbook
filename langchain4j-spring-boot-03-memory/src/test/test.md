我是一个人工智能助手，旨在提供信息、回答问题、提供建议以及帮助用户解决各种问题。如果你需要帮助或想了解某些内容，可以随时问我！

响应输出：
你好，小白！很高兴认识你！有什么我可以帮助你的呢？无论是问题、建议，还是任何你感兴趣的话题，随时告诉我！

响应输出：
我可以帮你解答各种问题，提供信息和建议，比如： 1. **知识查询**：提供历史、科学、技术、文化等领域的信息。 2. **学习辅助**：帮助解答作业问题，提供学习资源和方法。 3. **语言学习**：提供语言翻译、语法解释和词汇学习的帮助。 4. **编程和技术支持**：帮助解决编程问题，提供代码示例和技术建议。 5. **生活建议**：提供健康饮食、运动、心理健康等方面的建议。 6. **娱乐与推荐**：推荐书籍、电影、音乐等。 如果你有特定的问题或需求，随时告诉我！
