# 失物招领智能助手

## 功能列表

### 1. 失物登记
- **功能描述**：失主登记丢失的物品信息
- **使用场景**：用户丢失物品后，通过对话登记失物信息（姓名、手机号、物品名称、特征描述等）
- **支持补录**：如果用户之前已登记过，可以补充完善物品特征信息

### 2. 拾物登记
- **功能描述**：拾得者登记拾取到的物品信息
- **使用场景**：用户捡到他人丢失的物品后，通过对话登记拾物信息（姓名、联系电话、物品名称、特征描述等）
- **支持补录**：如果用户之前已登记过，可以补充完善物品特征信息

### 3. 失物查询
- **功能描述**：失主查询自己丢失的物品是否被他人捡到
- **使用场景**：用户想确认自己的失物是否有被找回
- **查询逻辑**：
  1. 根据失主手机号查询其登记的失物信息
  2. 根据失物名称和特征，在拾物登记表中查找匹配的记录
  3. AI智能匹配物品相似度，返回最佳匹配结果
  4. 如果找到，提供拾得人联系方式；如果未找到，建议稍后再查

## 技术特点

- **AI意图识别**：自动判断用户是想登记失物、登记拾物还是查询失物
- **智能对话**：基于LangChain4j的AI助手，支持多轮对话和信息收集
- **结构化输出**：使用JSON Schema约束AI输出，确保数据格式规范
- **记忆管理**：自动记录对话历史，支持上下文理解
- **数据库持久化**：使用JPA将登记信息保存到MySQL数据库
